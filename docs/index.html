Cross-Platform Macro & Stream Deck Studio

PoundControl

Open-source, local-first macro and stream deck for Windows, macOS, Linux, LAN phones/tablets, Android, and Wear OS watches. Pair a clickable Virtual Desktop Deck and encrypted touch decks with built-in OBS Studio, Soundboard, Elgato .sdPlugin, and sandboxed WebAssembly plugins.

Desktop Studio & Virtual Deck

PoundControl Studio is built with Go and Fyne v2 so your full deck editor runs natively on desktop with zero cloud account requirements.

Flexible Profiles, Pages & Folders

Organize buttons and rotary encoder dials across profiles, pages, and nested folders with drag/move, auto-swap, and cross-profile copy/paste.

Keep a lightweight Virtual Desktop Deck floating over your workspace alongside global keyboard hotkeys for instant triggers anywhere.

Visual Multi-Action Sequences

Combine actions across built-in, .sdPlugin, and WebAssembly plugins into deterministic multi-step automations right inside the Action Inspector.

  • Step Delays & Reordering: Insert timed waits between actions, reorder steps, or duplicate existing steps with one click.
  • Inline Editing & Muting: Adjust individual step settings inline or mute steps temporarily while iterating without deleting them.
  • Live Test Runs: Trigger sequences directly from the editor to verify scene switches, audio cues, webhooks, and hotkeys before going live.

Encrypted LAN, Android & Wear OS Touch Decks

Turn any phone, tablet, or Wear OS smartwatch on your Wi-Fi network into a low-latency wireless deck without exposing unauthenticated ports.

Zero-Install LAN Web Deck

Scan a temporary QR code or enter a 6-digit pairing PIN to connect any browser. Configure independent per-device viewports or Follow-Studio mode.

Android Companion App

Dedicated Android 8.0+ app with QR pairing, fullscreen deck grid, tactile feedback, and Wear OS Wearable Data Layer bridging.

Wear OS Smartwatch Deck

Tap deck keys, navigate pages and folders, adjust rotary dials, or launch directly from a Wear OS watch face complication.

Cryptographic Pairing: Device pairing uses mutual Ed25519 + SPAKE2 + HMAC authentication and requires explicit approval inside Desktop Studio.

Built-In Plugins

PoundControl ships with four native plugins ready out of the box:

  • Core: Page navigation, folder entry/exit, profile switching, and Visual Multi-Action sequences.
  • OBS Studio (WebSocket v5): Switch scenes, toggle sources and filters, control audio mute/volume, and start/stop streaming or recording.
  • Soundboard: Polyphonic playback for WAV, MP3, OGG Vorbis, and FLAC clips with per-slot trigger modes, master volume, and output device selection.
  • Apps & System Control: Launch applications or scripts, open URLs, send HTTP or WebSocket webhooks, fire keyboard macros/hotkeys, and send media keys.

Elgato .sdPlugin & Sandboxed WebAssembly Extensions

Extend PoundControl using existing creator hardware plugins or write your own cross-platform plugins without platform-specific native toolchains.

  • Elgato Stream Deck (.sdPlugin) Host: Loads standard SDK v2/v3 bundles with an optional 1-click Node.js setup, WebView2/browser Property Inspector bridge, and OpenAction Marketplace browsing.
  • Sandboxed WebAssembly (wazero) Runtime: Executes single-file .wasm WASI Preview 1 reactor plugins compiled from Go, TinyGo, Rust, Zig, or C/C++, complete with a Curated Catalog and SHA-256 verified updates. See the full Wasm Plugin ABI Reference.

Security, Keyring & Local-First Design

  • Local Configuration: Profiles, layouts, and plugin configurations live on your machine rather than third-party servers.
  • OS Keyring Secret Storage: Sensitive fields declared with "type": "password" in plugin global settings are stored in your operating system keyring rather than plaintext JSON.
  • Strict Wasm Sandboxing: WebAssembly plugins run with a 32 MiB memory cap, strict call/HTTP timeouts, zero host filesystem preopens, and manifest allowedHosts HTTP allowlisting.
  • SLSA Provenance Releases: Official binaries, APKs, and installers include SHA-256 checksums and keyless GitHub Actions SLSA Build Provenance attestations.
