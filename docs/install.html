Getting Started

Download & Install PoundControl

Pick the release package for your desktop operating system, phone, or smartwatch from the Latest GitHub Release.

Open Latest Release on GitHub

Release Downloads Overview

Every tagged release publishes prebuilt artifacts for desktop and mobile platforms along with checksums and GitHub Actions SLSA provenance attestations.

Official release artifacts by platform
Platform Recommended Download Notes
Windows (64-bit) PoundControl-v*-windows-amd64-setup.exe Guided installer with shortcuts, clean uninstall, and SHA-256 self-updates (portable .exe also available).
macOS (Apple Silicon) PoundControl-v*-darwin-arm64.zip Extracts PoundControl.app for Apple Silicon Macs.
Linux (x86_64) PoundControl-v*-linux-amd64.tar.gz Standalone poundcontrol binary archive for desktop Linux.
Android (8.0+) PoundControl-v*-android.apk Phone & tablet companion app; also acts as bridge for Wear OS watches.
Wear OS PoundControl-v*-wear.apk Smartwatch deck & watch face complication; pair via the Android companion app.

Windows (64-bit)

  • Guided Installer (Recommended): Download PoundControl-v*-windows-amd64-setup.exe and double-click to install with Start Menu / Desktop shortcuts, clean uninstall support, and automatic SHA-256 self-updates.
  • Portable Binary: Download PoundControl-v*-windows-amd64.exe and run it directly from any folder — no installation needed.
SmartScreen first-launch note: Because release binaries are not signed with a commercial EV certificate, Windows SmartScreen may show "Windows protected your PC". Click More info → Run anyway, or verify the binary using checksums / SLSA provenance below.

macOS

  1. Download PoundControl-v*-darwin-arm64.zip from the Latest Release and unzip it.
  2. Drag PoundControl.app into your Applications folder.
  3. On first launch, if macOS Gatekeeper warns about an unidentified developer, Control-click (right-click) PoundControl.app → Open → Open, or open System Settings → Privacy & Security → Open Anyway.

Linux (x86_64)

  1. Download PoundControl-v*-linux-amd64.tar.gz from the Latest Release.

Phone & Tablet Touch Deck (Zero-Install Browser Mode)

Use any phone, iPad, or secondary device on the same Wi-Fi network without installing an app:

  1. In PoundControl Desktop, open Settings → Web Deck and make sure Enable LAN Web Touch Deck is checked.
  2. Click Pair New Device to display a temporary 6-digit PIN and QR code.
  3. Scan the QR code with your phone/tablet camera (or open the shown URL and enter the PIN), then approve the pairing prompt in Desktop Studio.

Android Companion App

  1. On your Android phone or tablet (Android 8.0+), download PoundControl-v*-android.apk from the Latest Release.
  2. Tap the downloaded APK and allow Install unknown apps when prompted by Android.
  3. Launch PoundControl, open Settings → Web Deck → Pair New Device on your desktop, and scan the QR code to connect.

Wear OS Smartwatch Deck

The Wear OS watch app communicates with your desktop through the PoundControl Android companion app over Bluetooth/Wearable Data Layer:

  1. Install and pair the Android companion app (PoundControl-v*-android.apk) on the phone paired to your watch first.
  2. Enable Developer options → ADB debugging (or Wireless debugging) on your Wear OS watch and install PoundControl-v*-wear.apk (or sideload with a Wear OS installer app):

Launch PoundControl on your watch to tap deck buttons, navigate pages/folders, adjust rotary dials (bezel/crown), or add the PoundControl watch face complication. Your active page/folder viewport is remembered cleanly across reconnects.

First-Run Plugin & OBS Setup

After launching PoundControl Studio on your desktop:

  • OBS Studio (WebSocket v5): Open Settings → OBS Studio to pair with OBS on port 4455.
  • Curated WebAssembly Plugins: Open Settings → Plugins → Curated Catalog for 1-click installs of official integrations such as Twitch and TownCrier & Plugins.

See the step-by-step configuration guide for full details.
